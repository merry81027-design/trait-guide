我的 17 歲產品發表會｜Life Pitch Deck（2027 全新登場）

檔案：index.html

使用方式：
1. 解壓縮下載的 ZIP。
2. 將 index.html 放在 GitHub 專案根目錄（不要只把 ZIP 壓縮檔放進去）。
3. 將檔案 Commit 到 GitHub 目前實際存在的分支（例如 main）。
4. 在 Vercel 匯入該 GitHub repository，並選擇已存在且有 commit 的分支。
5. 推送更新後，Vercel 會自動重新部署。

網站流程與產出：
- 六個操作步驟，最後整理成 6 頁 Life Pitch Deck 簡報內容草稿。
- 首頁主標題為「2027 全新登場」，已移除時間、填答形式及副標說明。
- Slide 1：2027 產品定位、人設關鍵字與 OST。
- Slide 2：一開始先回顧 2026 年印象深刻的生活片段；任何正向、負向或普通但難忘的經驗都可以。接著回顧年度里程碑、產品指數與特質觀察。
- 產品指數選項包含「休眠時間」；選取後可以填寫平均每天睡眠時數（0–12 小時／日），其他指數則使用 0–100 趣味數值。
- Slide 3：Deprecation Notice，辨識要保留的能力、想停用的舊模式與過度使用警訊。
- Slide 4：兩項 2027 行動目標，搭配 WOOP 的 Wish、Outcome、Obstacle、If...Then... Plan。
- Slide 5：盤點內部優勢資源與外部支持系統。
- Slide 6：2027 上市宣言與關鍵字。
- 可逐頁複製、複製全部、下載文字稿，或列印／另存 PDF。
- 網站產出的是簡報內容草稿，不會直接產生 .pptx 或 Google Slides 檔案；學生可將各頁文字複製至簡報軟體，再自行編排視覺。

隱私與儲存：
- 回答僅儲存在學生目前瀏覽器的 localStorage，不會傳送至伺服器。
- 不使用資料庫、API 或外部 JavaScript 套件。
- 若使用共用裝置，完成後請下載成果並按「清除並重新製作」。
